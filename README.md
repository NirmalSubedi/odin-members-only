### Environment variables

## Skills demonstrated

- Securing user passwords with _bcrypt_ cryptographic hashing algorithm.

- Utilizing client session _cookies_ to retain user sessions.

- Keeping users session in between http requests with _express-session_.

- Allowing users to signup for an account and login into that account.

- Authenticating users with passport.js's `LocalStrategy` api.
